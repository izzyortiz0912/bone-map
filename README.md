# Bone map — SCB-203

Interactive study map of all 206 bones and every marking on the SCB-203 Bone List 2025.

- Clickable skeleton (front and back) with markings pinned on each bone, color-coded by marking type
- Skull from four angles, right hand, right foot, and five vertebra types
- Marking vocabulary tables linked to every matching marking
- Checklist of all 206 bones
- Practical drill: 25 stations, A and B at each, one minute per station

It's a single static file (`index.html`) with no build step. Open it in a browser, or deploy the repo to Vercel as-is.

Drawings are simplified study diagrams, not to scale.
